# Examples

This repository includes concrete examples to accelerate onboarding.

## Capability Authoring Example

- examples/capability_example.yaml

Shows a compact capability entry with mapping metadata.

## Mapping Conversion Example

- examples/conversion_example.json

Shows an example of translating an external framework identifier to a capability.

## Graph Export Examples
