# Documentation

This directory contains project-level documentation for OSCO architecture, ontology design,
authoring guides, governance, versioning, and best practices.

## Start Here

- [vision.md](vision.md): Project mission and non-goals.
- [architecture.md](architecture.md): High-level architecture and implemented-versus-planned scope.
- [ontology.md](ontology.md): Core semantic model, naming conventions, domain taxonomy, and enum definitions.
- [object-definitions.md](object-definitions.md): Canonical object responsibilities and key fields.

## Reference

- [field-reference.md](field-reference.md): Complete per-field documentation for every object — types, defaults, valid values, and semantic descriptions. Equivalent to OCSF's attribute dictionary.
- [relation-types.md](relation-types.md): Formal semantics for all mapping relation types and graph edge types, with a decision guide and confidence scoring guidelines.

## Authoring and Operations Guides

- [capability-authoring-guide.md](capability-authoring-guide.md): How to create and maintain capabilities.
- [provider-authoring-guide.md](provider-authoring-guide.md): How to model implementation providers.
- [mapping-guide.md](mapping-guide.md): Mapping strategy, relation types, OCSF alignment, and concrete examples.
- [discovery-guide.md](discovery-guide.md): Discovery state model and metadata.
- [verification-guide.md](verification-guide.md): Safe validation expectations.
- [versioning.md](versioning.md): Versioning strategy, status lifecycle, stable ID policy, and deprecation practice.
